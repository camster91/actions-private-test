# Security Policy

This repository currently contains only a manual echo workflow.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or security advisory feature for this repository if it is available. If not, contact the repository owner through a private GitHub channel. Do not include credentials, private information, or exploit details in public issues, pull requests, or workflow logs.

If a credential is exposed, revoke or rotate it first, then remove it from tracked files and repository history.
